# 使用说明

## 搜索与快捷键

- 直接输入关键字：匹配服务的名称、描述、地址、状态、标签与属性的键和值
- 命中命名空间名时，展示该命名空间下的全部服务
- `/` 聚焦搜索框，`Esc` 清空搜索并重新渲染

## 管理服务

- **新建服务**：点目录行尾的 `[+]`
- **编辑服务**：选中服务后，点详情头部的编辑按钮（在 JSON 编辑器里改）
- **新建命名空间**：点侧栏头部的 `[+]`

新建服务的初始草稿来自 `data/conf/service.schema.json`，在那里加一个字段，草稿里就多一个占位。

## 主题

页头可切换明暗与**强调色**，偏好保存在浏览器本地。

## 权限

页头的权限方框显示当前级别：`3` user 只读，`0` super 可写。

- 点击方框输入**服务密钥**即可提升：浏览器先在本地算 SHA-256 摘要，只把摘要发出去，明文不离开本机
- 服务端未配置密钥时无法提升，点击只会说明原因
- 若服务端配置了白名单（`server.permissionAllowlist`，默认放行回环与内网段），则只有名单内的网段能提升：在名单外的网络里点击会提示「当前来源地址不在权限提升白名单内」，需换到可信网络内操作
- **保存（写操作）默认同样受限**：即使摘要有效，名单外的网络里点保存也会提示「当前来源地址不在白名单内…，写操作被拒绝」；服务端可用 `server.digestAllowlistEnabled: false` 关掉这条限制（只放宽写操作，不影响提升）
- 若用 `http://内网IP` 访问，点击提升会提示「当前环境不提供 Web Crypto，请改用 https 或 localhost」—— 浏览器只在安全上下文提供摘要计算能力，客户端连请求都发不出去。两条出路：给面板配 TLS，或让服务端开启 `server.trustedNetworkBypass`（白名单内免密钥，见 `docs/api.md`）
